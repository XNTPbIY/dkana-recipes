📋 Функционал приложения "В гостях у DKana"
🎯 Основное назначение
Веб-приложение для управления рецептами домашних заготовок с автоматическим расчётом ингредиентов под разные объёмы банок и вес продуктов.

🔥 Ключевые функции
1. 📚 Менеджер рецептов
Создание рецептов
✅ Название рецепта
✅ Базовый объём (мл) - основа для пересчёта
✅ Неограниченное количество ингредиентов
✅ Пошаговые инструкции приготовления
✅ Заметки и советы
Поддерживаемые единицы измерения
Вес: граммы (гр), килограммы (кг)
Объём: миллилитры (мл), литры (л)
Количество: штуки (шт)
Специальные: столовые ложки (ст.л.), чайные ложки (ч.л.)
Управление
🔍 Поиск по названию в реальном времени
✏️ Редактирование существующих рецептов
🗑️ Удаление с подтверждением
📖 Просмотр в удобном формате
Пример рецепта
text

Название: Маринованные огурцы на зиму
Базовый объём: 1000 мл (1 литр)

Ингредиенты:
  • Огурцы свежие - 600 гр
  • Чеснок - 3 шт
  • Укроп (зонтики) - 2 шт
  • Соль - 30 гр
  • Сахар - 50 гр
  • Уксус 9% - 50 мл
  • Перец чёрный горошком - 5 шт
  • Лавровый лист - 2 шт

Инструкция:
1. Огурцы замочить в холодной воде на 3-4 часа
2. На дно стерилизованной банки положить укроп, чеснок, перец
3. Плотно уложить огурцы вертикально
4. Приготовить маринад: вскипятить воду, добавить соль и сахар
5. Залить огурцы кипящим маринадом
6. Добавить уксус
7. Стерилизовать 10 минут, закатать

Заметки: Хранить в прохладном тёмном месте
2. ⚖️ Калькулятор пропорций
Главная фишка приложения! Умный расчёт количества ингредиента в зависимости от веса/объёма продукта.

Как это работает
Задача: Нужно посолить мясо для вяления

Базовая пропорция: 30 гр соли на 1 кг мяса
У вас: 3.8 кг мяса
Результат: Автоматически рассчитает 114 гр соли
Режимы работы
🔢 Базовый расчёт
Укажите базовую пропорцию (например: 50 гр соли)
Выберите единицу измерения (гр, мл, шт и др.)
Укажите на какое количество продукта (например: на 1 кг рыбы)
Введите сколько у вас продукта (например: 2.5 кг)
Получите точный результат (125 гр соли)

3. 🫙 Калькулятор для банок
Автоматический пересчёт рецепта под банки любого объёма и количества.

text

  • Сахар - 600 гр
  • Уксус - 600 мл

11. 🧮 Математика и расчёты
Точность вычислений
Пропорции: расчёт с плавающей точкой
Округление: зависит от величины
Коэффициенты: точность до 0.01
Формулы
Расчёт пропорции:

text

Результат = (Базовое_количество_ингредиента / Базовое_количество_продукта) × Фактическое_количество_продукта
Расчёт для банок:

text

Коэффициент = (Объём_банки / Базовый_объём_рецепта) × Количество_банок
Новое_количество = Исходное_количество × Коэффициент
