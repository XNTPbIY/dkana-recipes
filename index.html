📲 Установка приложения

🤖 Android (Chrome)

  1. Нажмите ⋮ вверху справа
  2. Выберите "Установить приложение"
  3. Подтвердите
  4. Актуально если файл загружен на host

🍎 iPhone (Safari)

  1. Нажмите ⬆️ (Поделиться)
  2. Выберите "На экран Домой"
  3. Нажмите "Добавить"

🛠 Технологии

Приложение написано на чистых веб-технологиях без использования фреймворков:

HTML5 CSS3 JavaScript (Vanilla) LocalStorage PWA Flexbox/Grid

📚 Рецепты

Создавайте и храните свои любимые рецепты с точными пропорциями и инструкциями.

  • Добавление ингредиентов
  • Редактирование и удаление
  • Поиск по названию
  • Экспорт/импорт данных

⚖️ Пропорции

Мгновенный расчет ингредиентов для любого количества продукта.

  • Калькулятор соли, специй
  • Шаблоны для частых расчетов
  • История расчетов
  • Сохранение своих пропорций

🫙 Банки

Адаптируйте рецепты под любой объем банок.

  • Стандартные размеры (0.5л-3л)
  • Произвольный объем
  • Расчет для нескольких банок
  • Автоматическое масштабирование

💾 Данные

Полный контроль над вашими рецептами и настройками.

  • Резервное копирование (JSON)
  • Импорт из файла
  • Статистика использования
  • Безопасное удаление

📱 PWA Технология

Работает как нативное приложение на вашем устройстве.

  • Офлайн доступ
  • Быстрый запуск
  • Адаптивный дизайн
  • Темная тема

🎯 Советы

Как получить максимум от приложения:

  • Используйте шаблоны для частых расчетов
  • Добавляйте заметки к рецептам
  • Регулярно делайте резервные копии
  • Установите для быстрого доступа
